==================
1. Pycharm快捷键
==================


.. list-table:: PyCharm / IntelliJ IDEA 快捷键
   :widths: 25 75
   :header-rows: 1

   * - 快捷键
     - 功能说明
   * - Ctrl + Alt + S
     - 打开设置界面
   * - Ctrl + Shift + A
     - 查找动作（动作命令搜索）
   * - Ctrl + N
     - 查找类
   * - Ctrl + Shift + N
     - 查找文件
   * - Ctrl + F12
     - 显示文件结构
   * - Ctrl + Alt + L
     - 格式化代码
   * - Ctrl + Alt + O
     - 优化导入类和包
   * - Ctrl + /
     - 行注释 / 取消注释
   * - Ctrl + D
     - 复制当前行
   * - Ctrl + Y
     - 删除当前行
   * - Shift + F6
     - 重命名变量 / 方法 / 类
   * - Ctrl + Alt + V
     - 提取变量
   * - Ctrl + Alt + M
     - 提取方法
   * - Ctrl + Alt + T
     - 包裹代码（如 try/catch）
   * - Ctrl + Shift + ↑ / ↓
     - 方法间跳转
   * - Ctrl + Shift + U
     - 大小写转换
   * - Shift + Enter
     - 向下插入新行（可配合 Ctrl 代码补全）
   * - Ctrl + Alt + Enter
     - 向上插入新行
   * - Ctrl + G
     - 快速定位到指定行
   * - Alt + Insert
     - 生成代码（如 getter/setter、构造方法等）
   * - fori / sout / psvm + Tab
     - 快捷模板生成
   * - Ctrl + O
     - 重写方法
   * - Ctrl + I
     - 实现方法
   * - Alt + Enter
     - 导入包 / 自动修正提示
   * - Alt + /
     - 代码提示（快速补全）
   * - Ctrl + J
     - 查看可用的代码模板
   * - Ctrl + Shift + J
     - 合并两行代码
   * - Ctrl + Space
     - 基础代码补全
   * - Ctrl + Shift + Space
     - 智能代码补全（根据上下文推荐）
   * - Ctrl + Alt + I
     - 自动缩进当前代码
   * - Ctrl + E
     - 最近修改的文件
   * - Ctrl + Alt + Space
     - 类名 / 接口名提示
   * - Ctrl + P
     - 方法参数提示
   * - Ctrl + Q
     - 显示当前方法/类/变量的文档说明
   * - Ctrl + Shift + Backspace
     - 跳转到上次编辑的位置
   * - Ctrl + Alt + ← / →
     - 前后导航到编辑过的位置
   * - Alt + 7
     - 显示当前文件结构（侧边窗口）
   * - Ctrl + F12
     - 浮动显示文件结构
   * - Alt + F7
     - 查找函数/变量/类的所有引用
   * - Ctrl + Alt + F7
     - 快速查看所有引用
   * - Ctrl + Shift + F7
     - 高亮所有关键字引用
   * - Ctrl + R
     - 当前文件替换内容
   * - Ctrl + Shift + R
     - 全局批量替换



Windows
设置：Ctrl + Alt + S
复制一行：光标放任意位置，Ctrl + D
删除一行：Ctrl + Y
复制历史：Ctrl + Shift + V
纵向选择多行文本：Alt + 鼠标左键并拖动
选中下一个相同内容：Alt + J
选中所有同样的词：Shift + Ctrl + Alt + J
格式化：Ctrl + Alt + L
简单粘贴：Ctrl + Alt + Shift + V
返回撤销：Ctrl + Shift + Z
复制光标所在行：Ctrl + D
当前行向下/下移动一行：Alt + Shift + 上/下
多行移动：Shift + 上/下 + Alt
跳过一个词：Ctrl + 左/右
选中一个词：Ctrl + Shift + 左/右
选中当前文件中，所有一样的字符串：Ctrl + Shift + Alt + J
根据行号定位：Ctrl + G
加双括号或分号：Ctrl + Shift + Enter
大小写转换：Ctrl + Shift + U
tabs快速切换：Alt + 左/右
查看浏览过的文件：Ctrl + E
当前文件查找：Ctrl + F
当前文件替换：Ctrl + R
全局查找：Ctrl + Shift + F
全局替换：Ctrl + Shift + R
按文件名查找文件：Ctrl + Shift + N
查找所有的菜单和操作：Ctrl + Shift + A
查找文件、菜单、操作等，但不能查找文件内容：连按两次Shift
万能快捷键（智能辅助提示）：Alt + Enter
选中一大段代码：鼠标点击开始位置，找到尾行位置，按住Shift + 鼠标点击结尾位置
代码折叠和展开：Ctrl + Shift + +/-
类或方法的跳转：按住Ctrl + 鼠标左键
代码生成：Alt + Insert
查看方法调用情况：Ctrl + Alt + H
执行到当前方法的下一句：Step Over（F8）
进入当前行调用的方法体里：Step Into（F7）
执行完当前的方法：Step Out（Shift + F8）
进入到 Jar包方法里或 JDK 自带的方法里：Force Step Into（Alt + Shift + F7）
运行到光标所在处：Run to Cursor（Alt + F9）
Mac
优化import：⌃ + ⌥ + O
格式化代码：⌘ + ⌥ + L
删除当前行：⌘ + delete
复制当前行：⌘ + D
查看浏览过的文件：⌘ + E
选中下一个相同的内容：⌃ + G
选中文件中所有相同个的内容：⌃ + ⌘ + G
