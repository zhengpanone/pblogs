=================================================
AI、机器学习、深度学习、神经网络、大模型的关系
=================================================

总体关系: 人工智能(AI) ⊇ 机器学习(ML) ⊇ 深度学习(DL) ⊇ 深层神经网络 ⊇ 大模型

更准确地说：

- **AI** 是最宽泛的概念，涵盖所有模拟智能的方法
- **机器学习** 是 AI 的子集，强调从数据中学习
- **深度学习** 是机器学习的子集，使用深层神经网络
- **神经网络** 是一种模型结构，深层神经网络是深度学习的基础
- **大模型** 是深度学习发展到一定规模后的产物，通常基于 Transformer 架构

   :depth: 3
   :local:

逐层解释
========

人工智能（Artificial Intelligence, AI）
--------------------------------------------

**定义**
   让机器表现出"智能行为"的学科，涵盖推理、感知、决策、生成等能力。

**AI 模型**
   实现 AI 功能的数学模型或算法，包括：
   - 规则系统（专家系统）
   - 决策树、SVM 等传统机器学习模型
   - 神经网络 / 深度学习模型
   - 大模型（LLM、多模态模型等）

.. note::

   所有机器学习 / 深度学习 / 神经网络 / 大模型 都属于 AI 模型的范畴。


机器学习（Machine Learning, ML）
--------------------------------------------

**定位**
   AI 的一个子领域。

**核心思想**
   用数据 + 损失函数 + 优化算法，自动学习模型参数，而不是人工编写规则。

**典型算法**

- 线性回归 / 逻辑回归
- 决策树、随机森林
- SVM（支持向量机）
- K-Means / DBSCAN（聚类）
- 神经网络（部分简单网络也属于传统 ML）

**关键区分**

-  机器学习 ⊃ 深度学习
-  传统 ML 模型（如 SVM、决策树） **不是** 神经网络
-  神经网络是机器学习中的一类模型，但并非全部


深度学习（Deep Learning, DL）
--------------------------------------------

**定位**
   机器学习的一个子领域。

**核心特征**
   使用 **多层（深层）神经网络**，通过反向传播（Backpropagation）进行端到端学习。

**主要特点**

- 自动特征提取，无需人工设计特征
- 依赖大规模数据 + GPU 并行计算
- 层数越深，表示能力越强

**典型结构**

.. list-table:: 深度学习典型架构
   :header-rows: 1
   :widths: 25 35 40

   * - 架构
     - 擅长领域
     - 代表模型
   * - CNN（卷积神经网络）
     - 图像识别、目标检测
     - ResNet、VGG、YOLO
   * - RNN / LSTM / GRU
     - 序列数据（时序、文本）
     - LSTM、GRU
   * - Transformer
     - NLP、多模态、大模型基础
     - BERT、GPT、ViT

.. note::

   **深度学习 ≈ 深层神经网络 + 反向传播的学习方法**，二者不可分割。


神经网络（Neural Network）
--------------------------------------------

**定义**
   一种受生物神经元启发的数学模型，由大量节点（神经元）和连接（权重）组成。

**发展脉络**
   | 单层感知机 → 多层感知机（MLP） → 深度神经网络（DNN）

**关键理解**

- "神经网络" 本身是 **结构/架构**
- "深度学习" 强调的是用深层神经网络进行训练的方法
- **大模型** = 超大规模参数量的深层神经网络（通常是 Transformer）

.. note::

   不是所有神经网络都属于"深度学习"——浅层网络（如单隐层 MLP）属于传统机器学习的范畴。


大模型（Large Model / Foundation Model）
--------------------------------------------

**定义**
   深度学习 + 超大参数量 + 海量训练数据 + 自监督预训练。
   大模型是 **基于 Transformer 的深层神经网络**，经过大规模自监督预训练

**核心特征**

- **参数量**：亿级～万亿级
- **架构**：基于 Transformer 的深层神经网络
- **训练范式**：预训练 → 微调 / Prompt 工程 / RLHF
- **涌现能力**：参数量突破一定阈值后，出现小模型不具备的能力

**典型例子**

.. list-table:: 大模型分类
   :header-rows: 1
   :widths: 20 40 40

   * - 类型
     - 代表模型
     - 说明
   * - 语言大模型（LLM）
     - GPT-4、ChatGLM、LLaMA、DeepSeek
     - 文本生成、对话、推理
   * - 视觉大模型
     - ViT、SAM
     - 图像分类、分割
   * - 多模态大模型
     - CLIP、GPT-4V、DALL·E
     - 图文理解、文生图

.. note::

   大模型是深度学习 + 神经网络发展的高级形态，但不是唯一的深度学习应用方向（如 ResNet 做图像分类也是深度学习，但不是"大模型"）。

Q\&A
------------------

AI、机器学习、深度学习、神经网络、大模型的关系？
>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>
A:
- 人工智能(AI) ⊃ 机器学习(ML) ⊃ 深度学习(DL) ⊃ 深层神经网络 ⊃ 大模型
- 大模型是 **基于 Transformer 的深层神经网络**，经过大规模自监督预训练

传统机器学习 和 深度学习的区别？
>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>
A:
- 传统 ML：需人工设计特征（如 TF-IDF、HOG）
- 深度学习：自动特征学习，通过多层非线性变换
- 深度学习通常依赖 GPU + 大数据

神经网络 和 深度学习 是一回事吗？
>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>
A:
- 神经网络是 **模型结构**
- 深度学习是 **用深层神经网络 + 反向传播训练的方法**
- 浅层神经网络 ≠ 深度学习

为什么激活函数必不可少？
>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>
A:
- 若无非线性激活，多层网络等价于单层线性映射
- 常用：ReLU（避免梯度消失）、Sigmoid/Tanh（早期用）

CNN / RNN / Transformer 区别？
>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>
A:
- CNN：局部感受野，权值共享，适合图像
- RNN/LSTM：时序建模，串行计算，易梯度消失
- Transformer：Self‑Attention，并行，长依赖，适合大模型

什么是 Foundation Model（基础模型）？
>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>
A:
- 在大规模数据上预训练
- 可适配多种下游任务（微调 / prompt）
- 例：GPT、BERT、CLIP


单层神经元（感知机）
>>>>>>>>>>>>>>>>>>>>>>>>>>>

.. math::
    z = \sigma(w^T x + b)

线性回归预测
>>>>>>>>>>>>>>>>>>>>>>>>>>>

.. math::
    \hat{y} = w^T x + b

MSE 损失（回归）
>>>>>>>>>>>>>>>>>>>>>>>>>>>

.. math::
    L = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2

交叉熵损失（分类，二分类示例）
>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>

.. math::
    L = -\frac{1}{n}\sum [y \log \hat{y} + (1-y)\log(1-\hat{y})]

Softmax（多分类输出）
>>>>>>>>>>>>>>>>>>>>>>>>>>>

.. math::
    \text{Softmax}(z_i) = \frac{e^{z_i}}{\sum_j e^{z_j}}

梯度下降更新（核心思想）
>>>>>>>>>>>>>>>>>>>>>>>>>>>

.. math::
    \theta := \theta - \eta \nabla_\theta L(\theta)

Scaled Dot‑Product Attention（Transformer）
>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>
.. math::
    \text{Attention}(Q,K,V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right) V


训练流程 & 术语
>>>>>>>>>>>>>>>>>>>>>>>>>>>

- **Epoch**：整个数据集跑一遍
- **Batch / Mini‑batch**：一次更新用到的样本子集
- **Learning Rate(η)**：步长，过大不收敛，过小慢
- **Overfitting**：训练准高 / 验证准低  
  → 解决：正则化、Dropout、Early Stopping、更多数据
- **Underfitting**：模型太简单或训练不足

- **反向传播**：链式法则求梯度
- **预训练**：自监督任务（如下个 token 预测）
- **Fine‑tuning**：在特定任务标注数据上继续训练
- **RLHF**：基于人类偏好用强化学习进一步对齐模型输出

深度学习一定比传统 ML 好？
>>>>>>>>>>>>>>>>>>>>>>>>>>>

   不一定，小数据 + 结构化特征，传统 ML 往往更好

大模型 = 有人工智能 / 理解？
>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>

   否，本质是统计模式匹配，不是真正理解

ReLU 会导致死神经元？
>>>>>>>>>>>>>>>>>>>>>>>>>>>

   可能（负区梯度为 0），可用 Leaky ReLU / ELU

Attention 一定比 RNN 好？
>>>>>>>>>>>>>>>>>>>>>>>>>>>

   大多数 NLP 场景是，但 RNN 在小序列 / 在线流式仍有价值


总结
>>>>>>>>>>>>>>>

AI 是目标，ML 是数据驱动学习方法，
DL 是用深层神经网络做表示学习，
大模型是大规模 Transformer 预训练模型，
参数量大、数据大、算力大，
通过预训练 + 微调/RLHF 适配任务，
本质是函数拟合而非符号推理。

深入介绍：原理向进阶
====================

AI 模型在数学上是什么？
-----------------------------

> **本质上：一个可微/不可微的 函数近似器**

.. math::

    \hat{y} = f_\theta(x)

* :math:`x`：输入（文本 / 图像 / 数值）
* :math:`\theta`：模型参数（权重）
* :math:`f`：映射关系（线性 / 树 / 核 / 神经网络）
* :math:`\hat{y}`：预测结果

**不同 AI 模型 = 用不同函数族去逼近真实规律**

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - 类型
     - 函数形式
   * - 线性回归
     - :math:`f(x)=\mathbf{w}^{T}\mathbf{x}+b`
   * - 决策树
     - 分段常数函数
   * - SVM
     - 核函数映射
   * - 神经网络
     - 复合非线性变换（嵌套函数）

**神经网络 = 用很多简单非线性函数「嵌套」来逼近复杂函数（Universal Approximation Theorem）**

机器学习：它到底在“学”什么？
-----------------------------------

三大要素

* **假设空间（Model）**：比如“所有 3 层神经网络”
* **损失函数（Loss）**：
  * 回归：MSE

    .. math::

        L = \frac{1}{n}\sum (y-\hat{y})^2

  * 分类：交叉熵
* **优化算法（Optimizer）**：
  * 梯度下降（GD / SGD / Adam）

学习 = 最小化损失

.. math::

    \theta^* = \arg\min_\theta \mathbb{E}[L(f_\theta(x), y)]

传统 ML 常靠：
* 手工特征（TF‑IDF、HOG）
* 统计假设（朴素贝叶斯独立假设）

深度学习 **自动学特征表示**

神经网络：从神经元到深度网络
-----------------------------------

单个神经元（感知机）
>>>>>>>>>>>>>>>>>>>>>>>>>>

.. math::

    z = \sigma(w^Tx + b)

* :math:`w`：权重
* :math:`b`：偏置
* :math:`\sigma`：激活函数（Sigmoid / ReLU / Tanh）

> **没有激活函数 ⇒ 多层 = 一层（仍是线性）**

多层前馈网络（MLP / DNN）
>>>>>>>>>>>>>>>>>>>>>>>>>>

.. math::

    h_1 = \sigma(W_1x + b_1) \\
    h_2 = \sigma(W_2h_1 + b_2) \\
    \hat{y} = W_3h_2 + b_3

* 每层做：**线性变换 + 非线性**
* 深度 = 层数多 ⇒ 表达更复杂函数

反向传播（Backpropagation）
>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>

* 链式法则求 :math:`\frac{\partial L}{\partial w}`
* GPU 并行矩阵运算 ⇒ 能训深层网络

**深度学习 = 深层神经网络 + 反向传播 + 大规模数据**

深度学习典型架构演进（重点）
-----------------------------------

.. list-table::
   :header-rows: 1
   :widths: 20 20 60

   * - 架构
     - 擅长
     - 核心思想
   * - CNN
     - 图像
     - 局部感受野 + 权值共享 + 池化
   * - RNN/LSTM
     - 序列
     - 时间展开 + 隐状态
   * - Seq2Seq
     - 翻译
     - Encoder–Decoder
   * - Transformer
     - 语言/多模态
     - **Self-Attention** + 并行 + 长依赖


> **大模型几乎全基于 Transformer（2017 Attention is All You Need）**

Transformer 核心（简化理解）
>>>>>>>>>>>>>>>>>>>>>>>>>>>>>

* **Self‑Attention**：

  .. math::

      \text{Attention}(Q,K,V)=\text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V

* 每个 token 动态关注其他 token
* 并行计算 + 捕获长距离语义

相比 RNN：
* 可并行
* 梯度消失问题大幅缓解
* 更适合扩大参数量

大模型（Foundation Model）为什么“大”？
---------------------------------------------

所谓“大”指三点：

1. **参数量大** （亿～万亿）
   * GPT‑2：1.5B
   * GPT‑3：175B
2. **数据量大**
   * 网页文本 / 代码 / 书籍（TB 级）
3. **算力大**
   * A100/H100 集群，分布式训练（DP/TP/PP）

训练两阶段（关键）
>>>>>>>>>>>>>>>>>>>>>>

**预训练（Pre‑training）**
* **自监督学习**
* 任务示例（GPT）：
 
  > 给定前文，预测下一个 token

* 学会：语法、事实、常识、推理模式

**对齐（Fine‑tuning / RLHF）**

* SFT（监督微调）
* RLHF（人类反馈强化学习）
* 让输出 **有用、安全、符合指令**

为什么大模型“涌现”？
>>>>>>>>>>>>>>>>>>>>>>

* 并非线性提升
* 超过某参数量 + 数据 ⇒
  
  * 少样本学习（Few‑shot）
  * 推理、代码、翻译突然变好

（学界仍在深入研究严格理论）

大模型 ≠ 传统程序
-----------------------

.. list-table:: 大模型 VS 传统程序
   :header-rows: 1
   :widths: 20 40 40

   * - 对比
     - 传统软件
     - 大模型
   * - 逻辑
     - 明确 if‑else

   * - 可解释
     - 高
     - 低（黑盒）

     - 弱（规则死板）
     - 强（数据驱动）
   * - 错误类型
     - bug 
     - 幻觉（hallucination）
